# regions

Reference and reporting regions: IBRA 7, CAPAD, ACBR, ASPA, CCAMLR areas and MPAs; marine sets from imos-sor.

`acbr_v2_areas.csv`: the 16 ACBR v2 names and official ice-free areas from
ATCM Resolution 3 (2017) Annex, Table 1 (Terauds and Lee 2016; layer at
doi:10.4225/15/5729930925224).
